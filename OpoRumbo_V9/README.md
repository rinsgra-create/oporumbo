# OpoRumbo V9

Novedad principal: dos modos de estudio.

## Sin academia
OpoRumbo decide todo el plan del día usando progreso, resultados y bloques pendientes.

## Con academia
Se muestran todos los temas de la oposición.
El usuario marca uno o varios temas que le tocan hoy en la academia.
Esos temas pasan a ser tareas fijas.
OpoRumbo reorganiza alrededor:
- test del contenido marcado,
- repaso adaptativo de otros puntos débiles,
- inglés,
- psicotécnicos.

La selección del modo y los temas de academia se guardan con el progreso.
